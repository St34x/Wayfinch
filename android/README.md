# android

## Purpose
Gradle root of the Android app. Six pure `kotlin("jvm")` modules (no Android or network dependency; ENGINEERING.md
section 1): `protocol/`, `hud/`, `input/`, `module-api/`, `ui-tokens/`, `core/`.
Eight Android modules: `app/` (depends on all others; its merged manifest is the whole app), `shell/` (launcher),
`hermeslink/`, `glasses/`, `confirm/`, `skills/`, `status/`, `audio/`; today manifests and two placeholder activities
(closed at once). SDK 37 (Android 17) for compile, target and min. Fixed namespace/package: `app.hudcompanion[.<x>]`.

## Public API
- `./gradlew -PjvmOnly=true test` (`make test-android-jvm`): only the pure modules, no Android Gradle plugin, no SDK.
- `make test-android`: `assembleDebug test lint check`, needs `ANDROID_HOME`; `check` also dumps the release APK with
  `aapt2` (not debuggable, minSdk 37) and runs the Kotlin gates `detekt`, `ktlintCheck`, `sourceRules` and the planted
  `config/test-fixtures/` (tasks `*Fixtures`: a file fails exactly its `// expect:` rule), also with `-PjvmOnly=true`.
- `-PtestMinSdk=36`: test-only minSdk of the **debug** build type for the API 36 emulator; every other build type keeps
  37 (each module's `beforeVariants`), checked in the merged release manifest and the release APK.
- `make check-android-wrapper`, `make check-kotlin-gate-config` (static, in `make test`): wrapper pins, gate limits.
- `protocol/.../generated/Envelope.kt` is generated by `tools/codegen/gen_kotlin.py` (`make check-codegen` guards it);
  decode frames only with its strict `decodeEnvelope`, other JSON only with `StrictJson`; tests read `../protocol/fixtures`, the schema.
- `gradle.properties`: `appId` (application id only) and `appName` (`HUD Companion`) are placeholders until the app is renamed: the product is Wayfinch (top-level README); the Gradle project name `hud-companion` and the fixed package `app.hudcompanion` come from the project's working name "HUD Companion". No Gradle target runs in `make test` (they need a JDK, and `test-android` the Android SDK, which `make test` does not require); each stops with exit 2 and one line when its tool is missing.
- Revocation: `protocol/.../revoke/RevocationMarker` (`4403`, marked `403`), `core/.../revoke/` (flag, steps 0-6).

## Invariants
- Gradle 9.8.0 only, through the wrapper with `distributionSha256Sum`; Kotlin 2.2.10, the version of the built-in
  Kotlin of Android Gradle plugin 9.4.1, recorded once in `gradle/libs.versions.toml`; bytecode target JVM 21.
- Google groups (`com.android`, `androidx`, `com.google.android`, ...) resolve only from Google Maven, all others only
  from Maven Central (`exclusiveContent` in `settings.gradle.kts` and the root buildscript). No Play services library.
- `gradle/verification-metadata.xml` (SHA-256) and the lock files are generated, never hand-edited; a new or removed
  dependency needs both regenerated and its row in `docs/dependencies.md`. Lock files cover every project
  configuration; the build classpath is locked in the full build only (`-PjvmOnly=true` resolves a different one).
- Library modules build in explicit API mode (not `:app`). detekt and ktlint skip only `generatedDirs` (`// @generated`
  header) and `vendoredDirs` (provenance header, copied files only; `build.gradle.kts`); `sourceRules` rejects `!!` and
  `@Suppress` without `// reason`; gaps: ENGINEERING.md section 2, T1.282. Only `android/.editorconfig` may exist.
- Test libraries (MockWebServer, okhttp-tls) are test-only; `:app`'s unit tests (`sat/`) check the merged release
  manifest, the network security config, the backup rules (every domain, device-protected ones included), the shipped
  sources and the lock files (SAT-PL-01..11); `app/src/test/resources/sat/permission-allowlist.txt` lists permissions.
- No `<provider>` (SAT-PL-02): `androidx.startup` is removed, so `ProcessLifecycleOwner`, EmojiCompat and
  ProfileInstaller never start; code that needs one initialises it itself or uses another way (T1.25).
- Feature modules live under `modules/` ([README](modules/README.md)): `<id>/build.gradle.kts` becomes `:modules:<id>`.
