# glasses — Hermes gateway platform plugin

## Purpose

The `glasses` platform of the Hermes gateway and its operator CLI: config validation, device registry, allow-all
gate, envelope codec, the WebSocket session and `/enroll` mount (`server.py`, `server_session.py`), the edge listener on the unix socket `edge.socket` (`edge_listener.py`),
signer client, fail-closed adapter (`connect()` starts the listener or fails retryably; a `msg.in` becomes a Hermes text event; `send()` stores one `msg.out` per recipient in the outbox and writes it to a welcomed connection, which the outbox forgets when its session ends).

## Public API

- `register(ctx)` (`__init__.py`; manifest `plugin.yaml`); `adapter.py`, a Hermes `BasePlatformAdapter`: see Purpose; its frame router `adapter_router.py`. `inbound.py` (core, T1.08) — `msg.in` → lane checks (config `lanes` and the device's lanes, else `error` `lane_forbidden`; a route to an unserved profile, `lane_unrouted`), dedupe by `id` in memory (10 min, 1024 ids per device), the fields of `MessageEvent(TEXT)` with `user_id` = the authenticated device's id (the gateway applies `GLASSES_ALLOWED_USERS` to it); the event never controls the gateway (`allow_gateway_control=False`: no slash command, no answer to a pending approval or clarify prompt). `outbound.py` (core, T1.09b) — `send()`'s recipients (every non-revoked registry device holding the lane; `GLASSES_ALLOWED_USERS` stays inbound-only), the cut of `text` to 2048 B, the frames; `outbox.py` — `outbox.sqlite` (0600, own worker thread): `seq` per device, ack, replay on `hello` (`resumeFrom` = the first replayed `seq`; a device the registry lists as revoked is purged instead), TTL 24 h (applied at the next store, `hello` or start; no timer), cap 500 (`outbox_overflow`), `purge` of a revoked device (at `connect()`, at `send()`, at every `403` to a revoked device).
- `config*.py` + `config.schema.json` — settings under `gateway.platforms.glasses.extra`: `config.load()`, `check()`.
- `gate.py` — allow-all / wildcard gate (`violations()`), read the way the gateway reads it.
- `registry.py` — device registry `devices.json` (`add`, `lookup`, `revoke`); `registry_parse.py` its errors and strict read side (4 MiB cap, the `add` rules). No CA key here: the signer signs.
- `registry_signer_file.py` — `SignerFileRegistry`: the signer's `devices.json`, read-only (every `Registry` writer raises), fail closed on owner/mode/type of the file and of its directory (mode 0640 or stricter; a symlink is refused for the last path component only, the parents of `signer.public_dir` are the operator's: root- or signer-owned, not writable by the plugin user), no cache; `DenyOverlay` (`revoked-local.json`, a convenience copy held by the plugin's own user: that uid can drop an entry (effective at the next gateway restart) or add one (that phone is told it was revoked and wipes itself); real revocations go through the signer's tombstone; a denial whose write failed stays denied in memory and the next `deny` writes it again; a failed read of the signer's file is a typed `RegistryPermissionError`), `LastSeen` (`last-seen.json`). Wired by `adapter.connect()` (T1.184b); the live cut and alert on a bad file are T1.63a.
- Envelope codec, core; schema injected (`adapter._start_edge` loads `generated/envelope.schema.json`): `envelope.py` `decode`, `error_frame`;
  `envelope_scan.py`, `envelope_rules.py`, `envelope_encode.py` `encode` (`EncodeRefused`), `envelope_text.py` (`cut_utf8`).
- `server.py` — `build_app` (`/ws`: peer check, `authenticate`, hello/welcome, ping/pong, frame loop (`server_session.py`) with a 128 KiB/s inbound byte budget per connection, over it `1008`; WebSocket protocol pings are charged to that budget and answered by the loop, not by aiohttp's autoping; the socket is not read from the start of the upgrade to the WebSocket (what aiohttp had already read when the handler started, at most a read or two of 256 KiB, is all that is parsed at `prepare`) nor from a message taken to the next one (the yield, a pong write, `on_frame`), so a stream of tiny frames cannot pile up, not behind a slow `on_frame` nor behind a peer that does not read (a pong write unfinished after 5 s aborts the connection; held by the tests with a never-reading client of a tiny `SO_RCVBUF` and with `on_frame` blocked 2.5 s: growth under 100 MiB, loop gap under 250 ms; an `on_frame` that never returns holds its connection); 8 upgrades in flight per verified client certificate, then 503 (how often one certificate reaches the plugin is the edge's: we recommend a `limit_req` zone keyed on `$ssl_client_fingerprint`, e.g. 30 r/m, burst 10 for `/ws`, status 429); `/enroll` on one relay for every method) and `build_runner` / `serve` (`server_runner.py`: checks the aiohttp internals at start, `AiohttpDrift` otherwise; `serve` runs the app on the edge listener only). `edge_listener.py` — the unix socket `edge.socket` (lstat before bind: only a stale socket of the plugin's user is replaced; mode 0660; no TCP; each connection whose `SO_PEERCRED` uid is not `edge.user`'s is closed before a byte is read); `edge_auth.py` — `edge.user` to uid and the same `SO_PEERCRED` check as the request predicate of `/ws` and `/enroll`; `edge_cert.py` — the device identity of `/ws`: the forwarded client certificate (`client_cert_header` / `client_cert_encoding`) verified against the signer's `device-ca.pem` (re-read on change, at most once a second), its SHA-256 the fingerprint; a forwarded fingerprint header is never read. `connections.py` — one connection per device (a newer one closes the older with `4409`), one send queue and writer task each, `close_device` (abort after 500 ms). `server_auth.py` — `authenticate()` of the upgrade: 503 / 401 / 403 before any WebSocket. A malformed credential is refused before any registry read; the registry reads run in the module's own 4-thread pool, at most 32 requests deep, a hung-up client keeps its slot until a worker finishes (then 503), never in the loop's default executor. `revoked_ids.py` (T1.248, until the live cut T1.63a) — the injected `is_revoked`: the deny overlay, the outbox's purged ids and the signer's revoked ids, re-read on the check's own worker thread (2 s bound) when the file's stat (mtime, ctime, size, inode) changes, found by a check or a 0.5 s stat poll (`bind` to `close`); a frame or upgrade that meets the re-read is held for it (a second change during it: dropped / `503`); after a failed read checks refuse until a read succeeds (retried at most once a second); a device it finds newly revoked is purged and closed `4403` within about a second, idle sessions included (an idle session revoked only in the deny overlay: T1.63a).
- `signer_protocol.py` (core): `build_request`, `decode_answer`; `signer_client.py` sends them on the signer socket
  (callers: `crl`, `enroll.py`). Errors: `SignerError` → `RequestRefused` / `AnswerRejected` / `SignerRefusal`.
- Operator CLI `config check` (`admin.py`, `hermes_merge.py`, `hermes_facts.py`, `hermes_env.py`, `hermes_refs.py`; `--live` never writes and
  does not evaluate `${VAR}` fields, see `admin.py`), `crl` (`admin_crl.py`), `crl --check` (`crl_check.py`: published CA/CRL, `$state_dir/crl-seen.json`),
  `revoke` (`admin_devices.py`: signer `revoke`, then `$state_dir/admin.sock`, `admin_protocol.py`; a config with
  errors stops it before both steps; server planned, T1.63a); shared `admin_common.py`, `admin_names.py` (names `--live` may print); `python -m glasses.admin <cmd>`.

## Invariants

- Importing the package or calling `register` imports no Hermes module. Hermes is imported by `adapter.py` (and its `adapter_router.py`), by
  `hermes_facts.py`/`hermes_env.py` (`config check --live`) and by `gate.py` only when Hermes is already loaded in the process.
- Settings: an invalid value, or an access-control key the gateway would act on (`allow_from`, `allowed_users`, …),
  is an error. Any other unknown key is ignored with a warning that names it only when it is a key-like near-miss of
  a known key (`long_treshold` → `did you mean long_threshold?`), else `<an unknown key of N characters>`; injected keys are silent.
- Fail closed: no allow-all switch; a corrupt or unsafe registry or CRL record raises instead of
  admitting anyone. Device tokens are stored only as hashes and never logged. The allow-all gate reads the served
  profiles (a verdict is reused for 1 s, then always recomputed; a check waiting over 2 s for a blocked one is refused, and the check that runs the blocked read is refused after about 3 s, `LOCK_TIMEOUT` + 1); an unreadable scope is a violation, and any other check failure refuses too. A stalled gate check therefore holds the frame loop of the device that sent a `msg.in` for up to 3 s per `msg.in` (bounded, fails closed, a phone cannot trigger it). Dedupe and outbox limits (T1.249): a dedupe id counts only once its event was handed on (released when the hand-on raises, is cancelled or the allow-all gate drops the event). A device that sends `hello.lastAckedSeq` = 2^53−1 gets no outbox row again (it muted itself; re-enrolment gives a new id; one WARNING per device and process). A purged device never gets rows again, also when the plugin user removes its id from `revoked-local.json` and it authenticates after a restart (a revoked id is never reused). The state directory must be owned by the plugin user with mode `0700`, the only supported mode: last-seen, the deny overlay and `crl --check` refuse anything else; the outbox alone tolerates a readable `0755` one but refuses a group- or world-writable one at start (retryable).
- Core modules (the `core-purity` list in `.importlinter`) import no adapter, framework, Hermes package or I/O;
  `make check-imports` enforces it. `generated/` (protocol `TypedDict`s and the schema copy the adapter loads): `tools/codegen/` only, `make check-codegen`.
- Error frames (`envelope.py`, `inbound.py`) and signer errors (`signer_protocol.py`) never echo input: fixed messages, no chaining; no log line holds the text of a `msg.in` or of an answer.
- Targets Python 3.11–3.14 (Hermes' `requires-python`; tests run on 3.14, 3.11 planned): `make lint-py` checks 3.11 syntax, `make typecheck-py` 3.11 stdlib APIs (none mypy-ratcheted). `tests/` run without Hermes (`make test-plugin`).
